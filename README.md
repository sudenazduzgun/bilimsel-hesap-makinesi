# Bilimsel Hesap Makinesi

HTML, CSS ve JavaScript ile geliştirilmiş web tabanlı bilimsel hesap makinesi uygulaması.

## Özellikler
- **Temel İşlemler:** Toplama (`+`), çıkarma (`−`), çarpma (`*`), bölme (`/`)
- **Bilimsel & Matematiksel İşlemler:** `sin`, `cos`, `tan`, `ln`, `log`, `EXP` ($10^x$), `x²`, `yˣ`, `√`, `!` (faktöriyel), `1/x`, `abs` (mutlak değer), `%`, `e`, `π`
- **Hafıza (`Ans`):** Son hesaplanan sonucu ifadede yeniden kullanma
- **Ekran Kontrolü:** Başlatma (`disabled = false` / odaklama), temizleme, son karakteri silme ve kapatma

## Dosya Yapısı
- `hesap_makine.html` — Arayüz ve buton tanımları
- `hesap_makinesi.js` — Matematiksel işlemler ve `sonuc()` değerlendirme mantığı
- `hesap_makinesi.css` — Görünüm ve yerleşim stilleri

## Kullanım
1. Dosyaları aynı klasöre alın.
2. `hesap_makine.html` dosyasını tarayıcıda açın.
